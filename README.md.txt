# Olist Brazilian E-Commerce SQL Analysis

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset using PostgreSQL. The goal is to solve real-world business problems using SQL and generate actionable insights for marketplace growth, customer experience, logistics, and seller performance.

## Dataset

- Brazilian E-Commerce Public Dataset by Olist
- Database: PostgreSQL
- Tool: pgAdmin 4

## Business Problems Solved

1. Customer review score distribution
2. Impact of first delivery experience on repeat purchases
3. Highest revenue generating product categories
4. Sellers affecting customer experience
5. States with highest late delivery rates
6. Repeat purchase behavior analysis
7. Payment method and installment analysis
8. Revenue concentration among sellers
9. Most profitable customer states
10. Categories with highest shipping-cost-to-price ratio
